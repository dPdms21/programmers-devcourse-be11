## 실습 및 과제

> 자판기 과제

Java 기본 문법을 활용해 자판기 과제를 구현했다.   
과제를 구현하면서 입력, 조건문, 반복문, 메서드 분리, 반환값 처리 흐름을 연습했다.

주요 흐름은 다음과 같다.

- 초기 금액 입력
- 메뉴 출력
- 음료 선택
- 잔액 확인
- 금액 추가
- 프로그램 종료

## 헷갈렸던 점

메서드에서 변경한 값을 유지하려면 반환값을 다시 변수에 저장해야 한다.

```java
money = buyDrink(money, COKE, "콜라");
```

`switch`문에서는 메뉴 번호처럼 비교할 값을 먼저 입력받고, 각 `case`에서 처리한 뒤 `break`로 빠져나와야 한다.

## 오늘 느낀 점

Java 기본 문법은 이미 어느 정도 알고 있는 내용이라 수업이 다소 지루하게 느껴졌다.

다만 과제 구현을 통해 입력, 조건문, 반복문, 메서드 분리, 반환값 처리 흐름을 다시 점검할 수 있었다.

강의 내용을 그대로 따라가기보다는, 실습 코드와 핵심 개념 중심으로 다시 정리하는 방식이 나에게 더 잘 맞을 것 같다.

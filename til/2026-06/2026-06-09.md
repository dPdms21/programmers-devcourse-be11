## 오늘 배운 내용

오늘은 Java part2를 시작하면서 클래스와 객체 개념을 학습했다.

클래스를 통해 객체를 생성하는 방식과 객체의 필드, 메서드를 사용하는 흐름을 연습했다.  
또한 메서드의 선언부와 구현부, 매개변수, 반환값의 의미를 정리하고 계산기 예제를 통해 메서드 호출 과정을 확인했다.

인스턴스 변수와 클래스 변수의 차이도 학습했다.  
인스턴스 변수는 객체를 생성해야 사용할 수 있고, 클래스 변수는 `static`이 붙어 객체 없이 클래스명으로 접근할 수 있다는 점을 정리했다.

추가로 JVM 메모리 구조 기초와 `static` 메서드, 정적 중첩 클래스와 비정적 내부 클래스의 차이를 학습했다.

## 실습 및 과제

> Java 객체와 static 실습

`part2` 패키지를 새로 만들고 객체지향 기초 실습을 진행했다.

클래스와 객체 생성 방식을 실습하고, 계산기 예제를 통해 메서드 호출 흐름을 학습했다.  
또한 인스턴스 변수와 클래스 변수의 차이, JVM 메모리 구조, `static` 메서드 호출 방식, 정적 중첩 클래스와 내부 클래스의 차이를 확인했다.

> 자판기와 회원 관리 프로그램 static 제거

기존 자판기와 회원 관리 프로그램에서 불필요한 `static`을 제거하고, 객체가 직접 상태를 가지도록 리팩토링했다.

자판기 프로그램은 `money`와 `Scanner`를 필드로 이동했고,   
회원 관리 프로그램은 `totalCnt`, `memberCnt`, `members`, `Scanner`를 필드로 이동했다.  
`main()`은 객체 생성 후 `run()` 호출만 담당하도록 정리하고, 외부에서 직접 호출하지 않는 메서드는 `private`으로 변경했다.

> 업다운 게임 과제

업다운 게임 과제를 구현했다.

`Random`으로 정답을 생성하고, 사용자가 입력한 숫자에 따라 `UP`, `DOWN`, `정답`을 출력하도록 만들었다.  
기본 기능에 더해 난이도 선택, 기회 제한, 다시 하기, 중복 입력 방지 기능을 추가했다.

처음에는 `run()` 안에 모든 로직이 있었지만, 이후 입력 처리와 결과 출력 일부를 `private` 메서드로 분리해 흐름을 리팩토링했다.

## 헷갈렸던 점

오늘은 `static`이 붙은 멤버와 인스턴스 멤버의 차이가 가장 헷갈렸다.

처음에는 `static`이 붙으면 더 많은 것에 접근할 수 있다고 생각했지만,   
실제로는 객체 없이 존재하기 때문에 인스턴스 변수에는 직접 접근할 수 없다는 점을 다시 정리했다.  
반대로 인스턴스 메서드는 객체 안에서 실행되기 때문에 같은 객체의 필드를 바로 사용할 수 있었다.

정적 중첩 클래스와 비정적 내부 클래스의 차이도 헷갈렸다.  
정적 중첩 클래스는 바깥 객체 없이 생성할 수 있지만, 바깥 클래스의 인스턴스 변수에는 직접 접근할 수 없다.  
비정적 내부 클래스는 바깥 객체와 연결되어 생성되기 때문에 인스턴스 변수와 `static` 변수 모두 접근할 수 있다는 점을 확인했다.

업다운 게임에서는 입력 검증 흐름이 헷갈렸다.  
숫자가 아닌 입력, 범위 밖 입력, 이미 입력한 숫자는 아래 로직으로 내려가면 안 되기 때문에 `continue`로 다시 입력받도록 처리했다.

## 오늘 느낀 점

객체와 `static` 개념은 알고 있다고 생각했지만, 코드로 직접 구분하려니 생각보다 헷갈렸다.

특히 오늘은 문법을 외우는 것보다 “객체가 있어야 접근 가능한가, 객체 없이 접근 가능한가”를 기준으로 이해하는 것이 중요하다고 느꼈다.

Java 객체지향 기초는 앞으로 Spring 학습에서도 중요할 것 같아서 확실히 정리해야겠다고 느꼈다.

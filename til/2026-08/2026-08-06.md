## 오늘 배운 내용

오늘은 개발자 글쓰기 방법 특강을 듣고, 제2회 알고리즘 코딩테스트와 Web Project 과제에 응시했다.

개발자에게 필요한 경쟁력은 알고리즘과 코딩테스트, 컴퓨터공학 전공지식, 프로젝트 경험을 균형 있게 쌓으며 성장 가능성을 보여 주는 데서 만들어진다.

프로젝트에서는 기능 구현을 완료하는 것만으로 충분하지 않다.   
사용자 요구사항과 서비스 목표를 바탕으로 해결해야 할 문제를 정의하고, 기술을 선택한 이유와 해결 과정을 설명할 수 있어야 한다.

부하 테스트, 로깅, 메트릭 수집과 성능 모니터링을 활용하면 문제 상황과 개선 결과를 수치로 확인할 수 있다.   
서비스의 성능뿐 아니라 확장성, 신뢰성, 운영 비용까지 함께 고려해야 실제로 사용할 수 있는 서비스에 가까워진다.

포트폴리오에는 문제 상황, 기술 선택 이유, 시행착오, 기술적 타협과 결과를 구체적으로 기록해야 한다.   
기술 블로그에는 실패와 재시도를 포함해 해결 과정에서 어떤 판단을 했는지 자세히 남긴다.

이력서는 이러한 경험을 문제 상황, 해결 과정과 성과 중심으로 짧게 요약해 채용 담당자가 포트폴리오와 기술 블로그의 상세 내용을 확인하도록 연결하는 역할을 한다.

개발자 글쓰기는 사용한 기술을 나열하는 것이 아니라, 어떤 문제를 왜 해결했고 그 과정에서 무엇을 고민하고 배웠는지를 논리적이고 이해하기 쉽게 전달하는 과정이다.

## 실습 및 과제

> 개발자 글쓰기 방법 특강

신입 개발자에게 필요한 성장 가능성과 경쟁력을 컴퓨터공학 전공지식과 프로젝트 경험을 중심으로 확인했다.

프로젝트 경험을 기록할 때는 구현한 기능보다 문제를 발견한 배경과 해결 과정, 기술 선택의 근거와 결과가 드러나야 한다.

포트폴리오에는 하나의 문제를 해결한 전체 과정을 구체적으로 작성하고, 이력서에는 그중 핵심 내용과 성과만 간결하게 요약해야 한다.

기술 블로그에는 성공한 결과만 정리하기보다 실패한 접근과 재시도 과정, 판단이 바뀐 이유까지 남겨 자신의 문제 해결 과정을 보여 줄 수 있다.

> 제2회 알고리즘 코딩테스트

제2회 알고리즘 코딩테스트에 응시해 주어진 문제를 풀이했다.

이전 평가보다 전체적인 난이도는 낮게 느껴졌지만, 마지막 문제는 조건과 자료 구조를 정리하는 과정이 다소 까다로웠다.

개인 사정으로 참여하지 못했던 코딩 테스트 특강에서 다룬 문제와 유사한 접근이 필요했던 것 같다.  
특강 모의고사를 먼저 풀고 해설을 들었다면 문제를 구현하는 과정이 훨씬 수월했을 것 같다.

> 제2회 Web Project 과제

제2회 Web Project 과제에 응시해 제한 시간 안에 요구사항에 맞는 웹 애플리케이션을 구현했다.

전날 환경 확인 테스트를 통해 애플리케이션 빌드와 서버 실행, 자동 채점 흐름을 미리 경험한 덕분에 실제 평가 환경을 비교적 빠르게 파악할 수 있었다.

환경 확인 없이 바로 평가를 시작했다면 실행 방법과 채점 흐름을 이해하는 데 시간이 더 필요했을 것 같다.

## 헷갈렸던 점

알고리즘 코딩테스트에서는 중첩된 자료 구조에 값을 저장하고 다루는 부분이 아직 익숙하지 않은 것 같다.

문제에서 요구하는 데이터 구조를 바로 코드로 작성하기보다, 각 단계에서 어떤 값을 저장하고 조회해야 하는지 먼저 분리해 정리할 필요가 있었다.

코딩 테스트 특강에서 다룬 문제와 모의고사를 충분히 확인하지 못한 상태여서, 평가 중 유사한 접근이 필요할 때 풀이 방향을 잡는 데 시간이 걸렸다.

Web Project 과제에서는 구현 자체뿐 아니라 제한된 시간 안에 빌드와 서버 실행, 요청·응답 검증까지 모두 관리해야 했다.   
전날 환경 테스트에서 전체 진행 과정을 확인해 둔 것이 실제 평가에 도움이 됐다.

## 오늘 느낀 점

개발자 글쓰기에서는 많은 기술을 사용했다는 사실보다 어떤 문제를 발견했고, 왜 해당 기술을 선택했으며, 결과가 어떻게 달라졌는지를 설명하는 것이 중요하다고 느꼈다.

현재 진행 중인 프로젝트도 기능 목록만 정리하기보다 문제 상황, 해결 과정과 수치로 확인한 결과를 중심으로 기록해야   
포트폴리오에서 나의 역할과 판단을 명확하게 보여 줄 수 있을 것 같다.

알고리즘 코딩테스트는 이전보다 수월하게 풀었지만, 일부 문제에서는 자료 구조를 정확하게 구성하는 연습이 더 필요했다.   
참여하지 못한 특강의 모의고사를 미리 풀어보지 않은 점은 아쉬웠다.

코딩테스트에 이어 Web Project 과제까지 오랜 시간 평가를 진행해 체력적으로 힘들었다.   
그래도 환경 확인 테스트를 미리 진행한 덕분에 실제 과제에서는 실행 환경보다 구현에 집중할 수 있었다.

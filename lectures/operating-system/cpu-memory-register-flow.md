# CPU, 메모리, 레지스터의 동작 흐름

## 정리 목적

CPU가 메모리에 저장된 명령어와 데이터를 읽고, 필요한 값을 레지스터에 적재한 뒤 연산을 수행하는 흐름을 정리한다.

---

## 핵심 개념

### CPU

CPU는 메모리에 저장된 명령어를 읽고 해석한 뒤 실행하는 장치이다.  
프로그램 실행 과정에서 필요한 데이터를 가져오고, 연산을 수행하며, 결과를 저장한다.

### 메모리

메모리는 현재 실행 중인 프로그램의 명령어와 데이터를 저장하는 공간이다.  
CPU는 프로그램을 실행할 때 메모리에 저장된 명령어와 데이터를 읽어온다.

### 레지스터

레지스터는 CPU 내부에 있는 매우 빠른 임시 저장 공간이다.  
CPU는 메모리에 있는 값을 직접 연산하지 않고, 필요한 값을 레지스터에 적재한 뒤 연산한다.

---

## CPU의 명령어 실행 흐름

CPU는 보통 다음과 같은 흐름으로 명령어를 실행한다.

```text
메모리에서 명령어 가져오기
→ 명령어 해석하기
→ 필요한 데이터 읽기
→ 레지스터에 값 적재하기
→ 레지스터 값으로 연산하기
→ 결과 저장하기
```

---

## 예시

다음과 같은 연산을 생각해볼 수 있다.

```text
a = 10
b = 20
c = a + b
```

이때 `a`와 `b`의 값은 메모리에 저장되어 있다.  
CPU가 두 값을 더하려면 먼저 메모리에서 값을 읽어 레지스터에 적재해야 한다.

```text
LOAD R1, 100   // 메모리 100번 주소의 값을 R1에 저장
LOAD R2, 104   // 메모리 104번 주소의 값을 R2에 저장
ADD R3, R1, R2 // R1과 R2를 더해 R3에 저장
STORE R3, 108  // R3의 값을 메모리 108번 주소에 저장
```

예를 들어 메모리 100번 주소에 `10`, 104번 주소에 `20`이 있다면 다음과 같이 동작한다.

```text
메모리 100번 주소: 10 → R1
메모리 104번 주소: 20 → R2
R1 + R2 = R3
R3: 30 → 메모리 108번 주소
```

즉, CPU는 메모리의 값을 바로 계산하지 않고, 레지스터에 가져온 값을 기준으로 연산한다.

---

## 전체 흐름 요약

```text
1. 프로그램이 실행되면 명령어와 데이터가 메모리에 올라간다.
2. CPU는 메모리에서 명령어를 가져온다.
3. 명령어를 해석하고 필요한 데이터를 읽는다.
4. 읽어온 데이터는 레지스터에 적재된다.
5. CPU는 레지스터 값을 이용해 연산한다.
6. 연산 결과는 레지스터나 메모리에 저장된다.
```

---

## 핵심 정리

CPU는 메모리에서 명령어와 데이터를 가져와 실행한다.  
이때 연산에 필요한 값은 먼저 레지스터에 적재되고, CPU는 레지스터에 있는 값을 이용해 연산한다.

따라서 프로그램 실행 흐름은 다음처럼 이해할 수 있다.

```text
메모리 → 레지스터 → CPU 연산 → 레지스터 또는 메모리에 결과 저장
```

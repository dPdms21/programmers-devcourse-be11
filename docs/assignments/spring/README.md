## 학습 흐름

1. 객체지향 설계 원칙에서는 SOLID 5원칙을 적용해 변경에 유연한 구조로 리팩터링한다.
2. 디자인 패턴에서는 변하는 작업을 전략으로 분리하고, 전략 구현을 별도 클래스에서 익명 클래스와 람다로 단순화한다.
3. 제어의 역전 · 싱글톤에서는 객체 생성과 실행 흐름의 제어권을 외부로 분리하고, 싱글톤과 무상태 구조를 구현한다.
4. 테스트 코드에서는 JUnit 5로 정상 동작과 예외 상황을 자동 검증하고, Spring 테스트 컨텍스트를 통해 빈을 주입받는다.
5. 예외 처리에서는 복구 · 회피 · 전환 전략을 적용하고, 재시도 과정과 예외 발생 내용을 파일 로그로 기록한다.

# 자판기 과제

## 주어진 코드

```java
static final int COKE = 500, CIDER = 700, FANTA = 300, WATER = 200;

public static void printMenu(int totalMoney) {
    System.out.println("================================= 자판기 ================================");
    System.out.println("[1]콜라-500원 [2]사이다-700원 [3]환타-300원 [4]물-200원 [5]돈넣기 [6]종료");
    System.out.println("현재 금액 : " + totalMoney + "원");
    System.out.println("==========================================================================");
}
```

## 요구사항 요약

- 음료 가격을 상수로 정의한다.
- 현재 금액을 메뉴에 출력한다.
- 사용자에게 메뉴 번호를 입력받는다.
- 콜라, 사이다, 환타, 물을 선택하면 해당 음료를 구매한다.
- 잔액이 충분하면 음료 가격만큼 현재 금액에서 차감한다.
- 잔액이 부족하면 구매하지 않고 잔액 부족 메시지를 출력한다.
- 돈 넣기 메뉴를 통해 금액을 추가할 수 있다.
- 종료 메뉴를 선택하면 프로그램을 종료한다.

## 구현한 기능

- 자판기 메뉴 출력
- 현재 금액 출력
- 콜라 구매 기능
- 사이다 구매 기능
- 환타 구매 기능
- 물 구매 기능
- 잔액 부족 처리
- 금액 추가 기능
- 프로그램 종료 기능
- 객체가 현재 금액을 상태로 가지도록 구조 개선

## 리팩토링 내용

초기 구조에서는 현재 금액을 `main()`의 지역변수로 관리하고, 메서드에 매개변수로 전달한 뒤 반환값을 다시 받는 방식이었다.

리팩토링 후에는 `money`와 `Scanner`를 `VendingMachine` 클래스의 필드로 이동했다.

이를 통해 자판기 객체가 현재 금액이라는 상태를 직접 가지도록 변경했다.

또한 `main()`은 객체를 생성하고 `run()`을 호출하는 역할만 담당하도록 정리했다.

```java
public static void main(String[] args) {
    VendingMachine vm = new VendingMachine();
    vm.run();
}
```

## 정리

이번 과제에서는 단순히 메뉴를 출력하는 코드에서 시작해, 사용자가 돈을 넣고 음료를 구매할 수 있는 자판기 프로그램을 구현했다.

추가로 `static` 중심 구조를 객체 중심 구조로 변경하면서, 객체가 상태를 가지고 메서드가 그 상태를 변경하는 흐름을 연습했다.

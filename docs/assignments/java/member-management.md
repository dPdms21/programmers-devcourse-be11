# 회원 관리 프로그램 만들기 (2차원 배열)

> `String[][]` 2차원 배열에 회원 정보를 저장하고, 회원 추가, 조회, 수정, 삭제 기능을 구현한다. 배열, `static` 변수와 메서드, 선형 검색, 배열 당기기 흐름을 학습한다.

---

## 1. 무엇을 만드나요?

회원 정보를 관리하는 콘솔 프로그램을 구현한다.

프로그램을 시작하면 요금제를 먼저 선택하고, 선택한 요금제에 따라 회원 정원이 정해진다.

이후 메뉴가 반복 출력되고, 사용자는 번호를 입력해 회원 관리 기능을 실행한다.

```text
[요금제를 선택하세요]
[1]Lite : 10명 [2]Basic : 20명 [3]Premium : 30명
> 2

[수행할 업무를 선택하세요 - 현재 회원수 : 0/20]
[1]회원추가 [2]회원조회(메일) [3]회원조회(이름)
[4]회원전체조회 [5]회원정보 수정 [6]회원삭제
[7]프로그램 종료
>
```

---

## 2. 요구사항 정리 (기능 명세)

| 번호 | 기능        | 설명                                           |
| -- | --------- | -------------------------------------------- |
| 0  | 요금제 선택    | Lite, Basic, Premium 중 하나를 선택하고 회원 정원을 정한다.  |
| 1  | 회원 추가     | 이름, 이메일, 연락처를 입력받아 저장한다. 정원 초과와 이메일 중복은 막는다. |
| 2  | 회원 조회(메일) | 이메일로 회원을 찾아 정보를 출력한다.                        |
| 3  | 회원 조회(이름) | 이름으로 회원을 찾아 정보를 출력한다.                        |
| 4  | 회원 전체 조회  | 등록된 모든 회원 정보를 출력한다.                          |
| 5  | 회원 정보 수정  | 이메일로 회원을 찾아 이름, 이메일, 연락처를 새 값으로 수정한다.        |
| 6  | 회원 삭제     | 이메일로 회원을 찾아 삭제하고, 뒤 회원들을 앞으로 당긴다.            |
| 7  | 종료        | 프로그램을 종료한다.                                  |

이메일은 회원을 구분하는 고유 식별자로 사용한다.

회원 조회, 수정, 삭제는 모두 이메일을 기준으로 한 명의 회원을 찾는다.

## 3. 핵심 개념

### 1. 2차원 배열로 회원 저장

회원 한 명은 한 줄, 회원의 속성은 각 열로 표현한다.

```text
String[][] members = new String[정원][3];

         열0(이름)   열1(이메일)        열2(연락처)
행0 →   "홍길동"    "hong@a.com"      "010-1111"
행1 →   "김철수"    "kim@b.com"       "010-2222"
...
```

* `members[i][0]`은 i번째 회원의 이름이다.
* `members[i][1]`은 i번째 회원의 이메일이다.
* `members[i][2]`는 i번째 회원의 연락처이다.

### 2. static 변수로 상태 공유

여러 메서드에서 함께 사용하는 값은 클래스 차원의 `static` 변수로 둔다.

```java
static int totalCnt = 0;   // 정원
static int memberCnt = 0;  // 현재 회원 수
```

`totalCnt`는 요금제 선택으로 결정되는 전체 정원이다.

`memberCnt`는 현재 회원 수이면서, 다음 회원을 저장할 배열 인덱스 역할도 한다.

### 3. 선형 검색 패턴

이메일이나 이름으로 회원을 찾을 때는 배열을 처음부터 끝까지 순회하면서 `equals()`로 비교한다.

```java
for (int i = 0; i < members.length; i++) {
    if (searchValue.equals(members[i][column])) {
        // 찾은 경우 처리
        return;
    }
}
```

문자열 비교는 `==`가 아니라 `.equals()`를 사용한다.

### 4. 삭제 후 배열 당기기

배열은 중간 칸을 자연스럽게 비울 수 없으므로, 회원을 삭제한 뒤에는 뒤에 있는 회원들을 한 칸씩 앞으로 옮긴다.

```text
삭제 전: [A][B][C][D]      B 삭제
당기기:  [A][C][D][ ]      C, D가 한 칸씩 앞으로 이동
```

## 4. 프로그램 구조 (메서드 역할)

| 메서드                          | 역할                             |
| ---------------------------- | ------------------------------ |
| `printPricePlan()`           | 요금제 메뉴를 출력하고 선택 번호를 반환한다.      |
| `printMenu(memberCnt)`       | 업무 메뉴를 출력하고 선택 번호를 반환한다.       |
| `addMember(members)`         | 회원을 추가한다. 정원과 이메일 중복을 검사한다.    |
| `checkEmail(members, email)` | 이메일 중복 여부를 판단한다.               |
| `selectEmail(members)`       | 이메일로 회원을 조회한다.                 |
| `selectName(members)`        | 이름으로 회원을 조회한다.                 |
| `selectAll(members)`         | 전체 회원을 조회한다.                   |
| `updateMember(members)`      | 회원 정보를 수정한다.                   |
| `deleteMember(members)`      | 회원을 삭제하고 배열을 앞으로 당긴다.          |
| `main()`                     | 요금제 선택, 배열 생성, 메뉴 반복 흐름을 담당한다. |

## 5. Step by Step

각 Step에는 목표, 할 일, 힌트, 확인 방법이 있다.

한 Step씩 구현한 뒤 실행 결과를 확인하면서 다음 Step으로 넘어간다.

---

### Step 1. 요금제 선택과 메뉴 골격 작성 (`printPricePlan`, `printMenu`, `main`)

**목표**: 요금제를 선택하면 해당 정원만큼 배열을 생성하고, 메뉴가 반복 출력되도록 만든다.

**할 일**

1. `printPricePlan()`에서 요금제 안내를 출력하고 선택 번호를 반환한다.
2. `main()`에서 선택값 `num`을 기준으로 `new String[num * 10][3]` 배열을 생성한다.
3. `totalCnt`에 `num * 10`을 저장한다.
4. `printMenu(memberCnt)`에서 현재 회원 수와 정원을 포함한 업무 메뉴를 출력한다.
5. `while(true)`와 `switch`문으로 메뉴 선택 흐름을 만든다.
6. `7`을 입력하면 프로그램을 종료한다.

**힌트**

```java
static int totalCnt = 0;
static int memberCnt = 0;

public static int printPricePlan() {
    Scanner sc = new Scanner(System.in);

    System.out.println("[요금제를 선택하세요]");
    System.out.println("[1]Lite : 10명 [2]Basic : 20명 [3]Premium : 30명");

    return sc.nextInt();
}
```

```java
int num = printPricePlan();

String[][] members = new String[num * 10][3];
totalCnt = num * 10;

while (true) {
    int choice = printMenu(memberCnt);

    switch (choice) {
        case 1:
            break;
        case 7:
            System.out.println("이용해주셔서 감사합니다.");
            return;
        default:
            System.out.println("올바른 번호를 입력하세요.");
    }
}
```

**확인**: 요금제 선택 후 메뉴가 반복 출력되고, `7`을 입력하면 종료되면 성공이다.

---

### Step 2. 회원 추가와 중복 체크 구현 (`addMember`, `checkEmail`)

**목표**: 이름, 이메일, 연락처를 입력받아 배열에 저장한다. 정원 초과와 이메일 중복은 막는다.

**할 일**

1. `memberCnt == members.length`이면 "회원이 꽉 찼습니다."를 출력하고 종료한다.
2. 이름, 이메일, 연락처를 입력받는다.
3. `checkEmail(members, email)`이 `true`이면 "이미 존재하는 회원입니다."를 출력하고 종료한다.
4. `members[memberCnt]`에 이름, 이메일, 연락처를 저장한다.
5. 저장 후 `memberCnt`를 1 증가시킨다.

**힌트**

```java
public static boolean checkEmail(String[][] members, String email) {
    for (int i = 0; i < members.length; i++) {
        if (email.equals(members[i][1])) {
            return true;
        }
    }

    return false;
}
```

```java
members[memberCnt][0] = name;
members[memberCnt][1] = email;
members[memberCnt][2] = phone;

memberCnt++;
```

### Scanner 주의

메뉴 번호를 `nextInt()`로 받고 이름, 이메일, 연락처를 `nextLine()`으로 받으면 입력이 꼬일 수 있다.

`nextInt()`는 Enter를 버퍼에 남기기 때문에, 다음 `nextLine()`이 빈 문자열을 읽는 문제가 발생할 수 있다.

이를 막기 위해 `Scanner`는 하나만 만들어 공유하고, `nextInt()` 뒤에는 `nextLine()`으로 남은 줄바꿈을 제거한다.

**확인**: 회원 추가 후 전체 조회에서 추가한 회원이 보이면 성공이다. 같은 이메일로 다시 추가했을 때 거부되면 성공이다.

---

### Step 3. 이메일로 조회 구현 (`selectEmail`)

**목표**: 입력한 이메일과 일치하는 회원을 찾아 출력한다.

**할 일**

1. 이메일을 입력받는다.
2. 선형 검색으로 `members[i][1]`과 입력한 이메일을 비교한다.
3. 회원을 찾으면 정보를 출력하고 종료한다.
4. 끝까지 찾지 못하면 "찾으시는 정보가 없습니다."를 출력한다.

**힌트**

```java
for (int i = 0; i < members.length; i++) {
    if (email.equals(members[i][1])) {
        System.out.println("[이름] " + members[i][0]
                + ", [이메일] " + members[i][1]
                + ", [연락처] " + members[i][2]);
        return;
    }
}

System.out.println("찾으시는 정보가 없습니다.");
```

**확인**: 등록한 이메일로 조회했을 때 회원 정보가 출력되면 성공이다. 없는 이메일을 입력했을 때 안내 메시지가 출력되면 성공이다.

---

### Step 4. 이름으로 조회 구현 (`selectName`)

**목표**: 입력한 이름과 일치하는 회원을 찾아 출력한다.

**할 일**

1. 이름을 입력받는다.
2. 선형 검색으로 `members[i][0]`과 입력한 이름을 비교한다.
3. 회원을 찾으면 정보를 출력하고 종료한다.
4. 끝까지 찾지 못하면 안내 메시지를 출력한다.

이메일 조회와 같은 흐름을 사용하되, 비교 대상을 `members[i][1]`이 아니라 `members[i][0]`으로 바꾼다.

**확인**: 등록한 이름으로 조회했을 때 회원 정보가 출력되면 성공이다.

같은 이름이 여러 명인 경우 현재 구조에서는 처음 찾은 한 명만 출력된다.

---

### Step 5. 전체 조회 구현 (`selectAll`)

**목표**: 등록된 회원을 모두 출력한다.

**할 일**

1. 반복문을 사용해 회원 정보를 출력한다.
2. 빈 칸이 출력되지 않도록 `memberCnt`까지만 반복한다.

**힌트**

```java
for (int i = 0; i < memberCnt; i++) {
    System.out.println("[이름] " + members[i][0]
            + ", [이메일] " + members[i][1]
            + ", [연락처] " + members[i][2]);
}
```

`members.length`는 전체 정원이므로 아직 채워지지 않은 칸까지 포함한다.

전체 조회에서는 등록된 회원 수인 `memberCnt`까지만 반복해야 빈 칸 `null`이 출력되지 않는다.

**확인**: 등록한 회원만 빠짐없이 출력되고, 빈 칸이 출력되지 않으면 성공이다.

---

### Step 6. 정보 수정 구현 (`updateMember`)

**목표**: 이메일로 회원을 찾아 이름, 이메일, 연락처를 새 값으로 수정한다.

**할 일**

1. 수정할 회원의 이메일을 입력받는다.
2. 선형 검색으로 해당 이메일을 가진 회원의 인덱스 `idx`를 찾는다.
3. 찾지 못하면 "찾으시는 회원이 없습니다."를 출력하고 종료한다.
4. 새 이름, 새 이메일, 새 연락처를 입력받는다.
5. `members[idx]`의 값을 새 값으로 변경한다.
6. "수정이 완료되었습니다."를 출력한다.

**힌트**

```java
int idx = -1;

for (int i = 0; i < members.length; i++) {
    if (email.equals(members[i][1])) {
        idx = i;
        break;
    }
}

if (idx == -1) {
    System.out.println("찾으시는 회원이 없습니다.");
    return;
}
```

**확인**: 수정 후 이메일 조회나 전체 조회를 했을 때 바뀐 정보가 출력되면 성공이다.

---

### Step 7. 회원 삭제와 배열 당기기 구현 (`deleteMember`)

**목표**: 이메일로 회원을 찾아 삭제하고, 뒤 회원들을 한 칸씩 앞으로 당긴다.

**할 일**

1. 삭제할 회원의 이메일을 입력받는다.
2. 선형 검색으로 해당 이메일을 가진 회원의 인덱스 `idx`를 찾는다.
3. 찾지 못하면 안내 메시지를 출력하고 종료한다.
4. `memberCnt`를 1 감소시킨다.
5. `idx`부터 마지막 회원 전까지 다음 회원 정보를 현재 위치로 복사한다.
6. 당긴 뒤 마지막에 남는 중복 데이터를 `null`로 정리한다.

**힌트**

```java
for (int i = idx; i < members.length - 1; i++) {
    members[i][0] = members[i + 1][0];
    members[i][1] = members[i + 1][1];
    members[i][2] = members[i + 1][2];
}
```

```java
members[memberCnt][0] = null;
members[memberCnt][1] = null;
members[memberCnt][2] = null;
```

삭제 후 배열을 당기지 않으면 중간에 빈 칸이 생긴다.

마지막 칸을 `null`로 정리하지 않으면 당긴 뒤 남은 중복 데이터가 배열 끝에 남을 수 있다.

**확인**: 가운데 회원을 삭제해도 전체 조회에서 빈 칸 없이 이어지고, 현재 회원 수가 1 감소하면 성공이다.

---

### Step 8. 마무리 다듬기

**목표**: 입력 문제와 예외 상황을 점검하고 프로그램을 완성한다.

**점검 항목**

* [ ] 입력이 한 칸씩 밀리거나 이름이 비는 문제가 없는지 확인한다.
* [ ] 현재 회원 수와 정원이 메뉴에 정확히 표시되는지 확인한다.
* [ ] 정원이 꽉 찼을 때 회원 추가가 막히는지 확인한다.
* [ ] 삭제 후 전체 조회 시 빈 칸이나 중복 회원이 출력되지 않는지 확인한다.
* [ ] 없는 회원을 조회, 수정, 삭제해도 프로그램이 멈추지 않는지 확인한다.

### Scanner 권장 방식

```java
static Scanner sc = new Scanner(System.in);
```

`Scanner`는 하나만 만들어 모든 메서드에서 공유한다.

`nextInt()` 뒤에는 남은 줄바꿈을 제거한다.

```java
int num = sc.nextInt();
sc.nextLine();
```

여기까지 통과하면 회원 관리 프로그램이 완성된다.

* [ ] 이름으로 회원을 조회한다.

* [ ] 회원 정보를 수정한다.

## 7. 개선 및 도전 과제

### 먼저 다듬으면 좋은 점

1. **전체 조회 범위 제한**: 전체 조회를 `memberCnt`까지만 반복해 빈 칸 `null` 출력 방지
2. **삭제 후 마지막 칸 정리**: 삭제 후 배열을 당긴 뒤 마지막 칸을 `null`로 정리
3. **Scanner 공유**: `Scanner`를 하나만 만들어 공유해 입력 꼬임 방지
4. **main 메서드 표준화**: 표준 실행을 위해 `public static void main(String[] args)` 형태로 유지

### 확장 도전 과제

1. **Member 클래스 도입**: `Member` 클래스를 만들어 이름, 이메일, 연락처를 하나의 객체로 관리
2. **ArrayList 적용**: 고정 크기 배열 대신 `ArrayList<Member>`로 변경해 정원 제한과 배열 당기기 코드 제거
3. **동명이인 처리**: 이름 조회 시 일치하는 회원을 모두 출력
4. **파일 저장**: 프로그램을 종료해도 회원 정보가 유지되도록 파일 저장과 불러오기 구현
5. **입력 검증**: 이메일 형식과 연락처 숫자 형식 검사

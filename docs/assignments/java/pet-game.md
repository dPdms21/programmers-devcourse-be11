# 반려동물 키우기 만들기 (객체지향 · 생성자)

> 반려동물 하나를 입양해서 먹이를 주고 놀아주는 콘솔 게임을 구현한다. 클래스, 객체, 생성자, `this`, 캡슐화, 메서드로 객체 상태를 변경하는 흐름을 학습한다.

---

## 1. 무엇을 만드나요?

이름을 지어 반려동물을 입양하고, 먹이주기와 놀아주기를 통해 포만감과 행복을 관리하는 콘솔 게임을 구현한다.

```text
반려동물의 이름을 지어주세요: 콩이
콩이이(가) 태어났어요!
[콩이] 포만감: 50 / 행복: 50

무엇을 할까요? [1]먹이주기 [2]놀아주기 [3]상태보기 [4]종료
> 1
콩이에게 먹이를 줬습니다.
[콩이] 포만감: 70 / 행복: 55
> 2
콩이와(과) 신나게 놀았습니다.
[콩이] 포만감: 60 / 행복: 75
```

## 2. 학습 목표

| 개념         | 설명                                      |
| ---------- | --------------------------------------- |
| 클래스와 객체    | `Pet` 클래스를 만들고, 실제 반려동물 객체를 생성한다.       |
| 생성자        | 객체를 생성할 때 이름을 정하고 기본 상태를 초기화한다.         |

| 캡슐화        | 포만감과 행복을 `private`으로 숨기고, 메서드로만 변경한다.   |

이 과제는 객체 하나를 다루기 때문에 객체지향의 기본 구조를 연습하기에 적합하다.

## 3. 핵심 개념

### 1. 클래스와 객체

`Pet` 클래스는 반려동물을 만들기 위한 설계도이다.

이 클래스를 사용해 `콩이`와 같은 실제 반려동물 객체를 생성한다.

### 2. 생성자

생성자는 객체를 만들 때 호출된다.

반려동물 이름을 전달받고, 포만감과 행복의 기본값을 설정한다.

```java
public Pet(String name) {
    this.name = name;
    this.fullness = 50;
    this.happiness = 50;
}
```

```java
Pet pet = new Pet("콩이");
```

### 3. this 키워드

매개변수 `name`과 필드 `name`의 이름이 같을 때 `this.name`은 현재 객체의 필드를 의미한다.

```java
this.name = name;
```

### 4. 캡슐화

포만감과 행복은 외부에서 직접 변경하지 못하도록 `private`으로 선언한다.

상태 변경은 `feed()`, `play()` 같은 메서드를 통해서만 이루어지도록 한다.

## 5. Step by Step

각 Step에는 목표, 할 일, 힌트, 확인 방법이 있다.

한 Step씩 구현한 뒤 실행 결과를 확인하면서 다음 Step으로 넘어간다.

---

### Step 1. 반려동물 설계도와 생성자 작성 (`Pet.java`)

**목표**: 이름, 포만감, 행복을 가진 `Pet` 클래스를 만들고 생성자로 객체를 초기화한다.

**할 일**

1. `name`, `fullness`, `happiness` 필드를 선언한다.
2. 필드는 외부에서 직접 접근하지 못하도록 `private`으로 선언한다.
3. 이름을 전달받는 생성자를 작성한다.
4. 포만감과 행복의 기본값을 50으로 설정한다.
5. 상태를 출력하는 `showStatus()` 메서드를 작성한다.
6. `Main.java`에서 `Pet` 객체를 생성하고 상태를 출력한다.

**힌트**

```java
public class Pet {
    private String name;
    private int fullness;
    private int happiness;

    public Pet(String name) {
        this.name = name;
        this.fullness = 50;
        this.happiness = 50;
    }

    public void showStatus() {
        System.out.println("[" + name + "] 포만감: " + fullness + " / 행복: " + happiness);
    }
}
```

```java
Pet pet = new Pet("콩이");
pet.showStatus();
```

**확인**: `[콩이] 포만감: 50 / 행복: 50`이 출력되면 성공이다.

---

### Step 2. 먹이주기 메서드 작성 (`Pet.java`)

**목표**: 먹이를 주면 포만감이 오르는 메서드를 만든다.

**할 일**

1. `feed()` 메서드를 작성한다.
2. 포만감을 20 증가시킨다.
3. 포만감이 100을 넘지 않도록 제한한다.
4. 행복을 5 증가시킨다.
5. 행복이 100을 넘지 않도록 제한한다.
6. 먹이주기 메시지를 출력한다.

**힌트**

```java
public void feed() {
    fullness += 20;

    if (fullness > 100) {
        fullness = 100;
    }

    happiness += 5;

    if (happiness > 100) {
        happiness = 100;
    }

    System.out.println(name + "에게 먹이를 줬습니다.");
}
```

```java
pet.feed();
pet.showStatus();
```

**확인**: `feed()` 호출 후 포만감과 행복이 증가하면 성공이다. 여러 번 호출해도 100을 넘지 않아야 한다.

---

### Step 3. 놀아주기 메서드 작성 (`Pet.java`)

**목표**: 놀아주면 행복이 오르고 포만감이 줄어드는 메서드를 만든다.

**할 일**

1. `play()` 메서드를 작성한다.
2. 행복을 20 증가시킨다.
3. 행복이 100을 넘지 않도록 제한한다.
4. 포만감을 10 감소시킨다.
5. 포만감이 0보다 작아지지 않도록 제한한다.
6. 놀아주기 메시지를 출력한다.

**힌트**

```java
public void play() {
    happiness += 20;

    if (happiness > 100) {
        happiness = 100;
    }

    fullness -= 10;

    if (fullness < 0) {
        fullness = 0;
    }

    System.out.println(name + "와(과) 신나게 놀았습니다.");
}
```

**확인**: `play()` 호출 후 행복은 증가하고 포만감은 감소하면 성공이다.

---

### Step 4. 메뉴로 직접 돌보기 (`Main.java`)

**목표**: 메뉴를 통해 먹이주기, 놀아주기, 상태보기, 종료 기능을 반복 실행한다.

**할 일**

1. `Scanner`로 반려동물 이름을 입력받는다.
2. 입력받은 이름으로 `Pet` 객체를 생성한다.
3. `while`문으로 메뉴를 반복 출력한다.
4. 메뉴 번호에 따라 `feed()`, `play()`, `showStatus()`를 호출한다.
5. `4`를 입력하면 프로그램을 종료한다.
6. 잘못된 번호를 입력하면 안내 메시지를 출력한다.

**힌트**

```java
import java.util.Scanner;

Scanner sc = new Scanner(System.in);

System.out.print("반려동물의 이름을 지어주세요: ");
String name = sc.nextLine();

Pet pet = new Pet(name);
pet.showStatus();

while (true) {
    System.out.println("\n무엇을 할까요? [1]먹이주기 [2]놀아주기 [3]상태보기 [4]종료");
    System.out.print("> ");

    int menu = Integer.parseInt(sc.nextLine());

    if (menu == 1) {
        pet.feed();
        pet.showStatus();
    } else if (menu == 2) {
        pet.play();
        pet.showStatus();
    } else if (menu == 3) {
        pet.showStatus();
    } else if (menu == 4) {
        System.out.println("종료합니다.");
        break;
    } else {
        System.out.println("1~4 중에서 입력해 주세요.");
    }
}
```

메뉴 번호를 `sc.nextInt()` 대신 `Integer.parseInt(sc.nextLine())`으로 받으면 입력 버퍼가 꼬이는 문제를 줄일 수 있다.

**확인**: 메뉴를 선택할 때마다 반려동물의 상태가 변경되고, `4`를 입력하면 종료되면 성공이다.

### Step 5. 마무리 다듬기

**목표**: 캡슐화, 상태 범위, 메뉴 흐름을 점검하고 프로그램을 완성한다.

**점검 항목**

* [ ] 필드가 `private`으로 선언되어 있는지 확인한다.
* [ ] 외부에서 필드를 직접 바꾸지 않고 메서드로만 상태를 변경하는지 확인한다.
* [ ] 포만감과 행복이 0~100 범위를 벗어나지 않는지 확인한다.
* [ ] 메뉴가 반복 출력되는지 확인한다.
* [ ] `4`를 입력하면 프로그램이 종료되는지 확인한다.
* [ ] 잘못된 번호를 입력해도 프로그램이 멈추지 않는지 확인한다.

여기까지 통과하면 반려동물 키우기 프로그램이 완성된다.

## 8. 선택 도전 과제

1. **잠자기**: `sleep()` 메서드로 포만감과 행복 회복
2. **기분 표시**: 행복 수치에 따라 기분 상태 출력
3. **시간 경과**: 행동할 때마다 포만감이 조금씩 줄어들도록 구현
4. **생성자 오버로딩**: 종류까지 정하는 생성자 `Pet(String name, String type)` 추가
5. **여러 마리 키우기**: 펫을 배열로 여러 마리 관리

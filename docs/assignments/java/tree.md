# 트리 자료구조 직접 만들기

## 1. 목표

정수 값을 저장하는 이진 검색 트리를 직접 구현하고 전위, 중위, 후위 순회를 이해한다.

세 가지 순회 방식은 왼쪽과 오른쪽 서브트리를 방문하는 구조는 같지만, 현재 노드를 방문하는 시점이 다르다.

이 과제에서는 제네릭을 사용하지 않고 `int` 값을 저장하는 이진 검색 트리를 구현한다.

---

## 2. 구현 기능

값을 트리에 삽입하고 세 가지 방식으로 전체 노드를 순회하는 `MyTree` 클래스를 구현한다.

* `insert(int value)` → 이진 검색 트리 규칙에 따라 값 삽입
* `preOrder()` → 전위 순회
* `inOrder()` → 중위 순회
* `postOrder()` → 후위 순회

사용 예시는 다음과 같다.

```java
MyTree tree = new MyTree();
int[] values = {50, 30, 70, 20, 40, 60, 80};
for (int v : values) tree.insert(v);

tree.preOrder();    // 전위: 50 30 20 40 70 60 80
tree.inOrder();     // 중위: 20 30 40 50 60 70 80
tree.postOrder();   // 후위: 20 40 30 60 80 70 50
```

위 값을 순서대로 삽입하면 다음과 같은 트리가 만들어진다.

```text
          50
        /    \
      30      70
     /  \    /  \
   20   40  60   80
```

## 4. 핵심 개념

### 4.1 트리 용어

* **루트**: 트리의 가장 위에 있는 시작 노드
* **자식**: 특정 노드 아래에 연결된 노드
* **잎**: 자식이 없는 노드
* **서브트리**: 특정 노드를 루트로 하는 하위 트리
* **높이**: 루트에서 가장 깊은 잎까지의 거리

이진 트리의 각 노드는 왼쪽 자식과 오른쪽 자식을 최대 하나씩 가질 수 있다.

---

### 4.2 이진 검색 트리

이진 검색 트리는 다음 규칙에 따라 값을 저장한다.

* 현재 노드보다 작은 값은 왼쪽에 저장한다.
* 현재 노드보다 큰 값은 오른쪽에 저장한다.
* 이 과제에서는 현재 노드와 같은 값은 추가하지 않는다.

이 규칙을 사용하면 원하는 값을 찾을 때 탐색 범위를 왼쪽 또는 오른쪽으로 줄일 수 있다.

---

### 4.3 트리 순회

트리 순회는 트리에 저장된 모든 노드를 빠짐없이 방문하는 과정이다.

이 과제에서는 항상 왼쪽 서브트리를 오른쪽 서브트리보다 먼저 방문한다. 세 순회의 차이는 현재 노드를 언제 방문하는지에 있다.

| 순회    | 방문 순서         | 특징             |
| ----- | ------------- | -------------- |
| 전위 순회 | 루트 → 왼쪽 → 오른쪽 | 현재 노드를 먼저 방문   |
| 중위 순회 | 왼쪽 → 루트 → 오른쪽 | 현재 노드를 가운데에 방문 |
| 후위 순회 | 왼쪽 → 오른쪽 → 루트 | 현재 노드를 마지막에 방문 |

세 순회 메서드는 구조가 거의 같으며 현재 노드를 출력하는 코드의 위치만 달라진다.

---

### 4.4 순회 방식의 활용

* **전위 순회**: 트리 구조를 복사하거나 저장할 때 활용
* **중위 순회**: 이진 검색 트리의 값을 오름차순으로 조회할 때 활용
* **후위 순회**: 자식 노드를 먼저 처리한 뒤 부모 노드를 처리할 때 활용

후위 순회는 트리 삭제나 폴더별 용량 계산처럼 하위 데이터를 먼저 처리해야 하는 작업에 사용할 수 있다.

### Step 1. 노드와 기본 구조 만들기

#### 목표

값과 왼쪽·오른쪽 자식을 저장하는 노드와 트리의 시작점인 루트를 구현한다.

#### 구현 내용

1. `Node` 내부 클래스를 만든다.
2. `Node`에 `value`, `left`, `right` 필드를 선언한다.
3. 생성자에서 전달받은 값을 `value`에 저장한다.
4. `MyTree`에 루트 노드를 저장하는 `root` 필드를 선언한다.

<details>
<summary>힌트 보기</summary>

```java
public class MyTree {

    static class Node {
        int value;
        Node left;
        Node right;
        Node(int value) {
            this.value = value;
        }
    }

    private Node root;   // 트리의 시작점
}
```

</details>

#### 확인

컴파일 오류가 발생하지 않으면 기본 구조가 완성된 것이다.

### Step 2. `insert` 구현

#### 목표

이진 검색 트리의 규칙에 따라 값을 삽입한다.

#### 구현 내용

1. 루트가 비어 있으면 새 노드를 루트로 설정한다.
2. 삽입할 값이 현재 노드보다 작으면 왼쪽 서브트리로 이동한다.
3. 삽입할 값이 현재 노드보다 크면 오른쪽 서브트리로 이동한다.
4. 빈 위치를 찾으면 새 노드를 생성한다.
5. 현재 노드와 같은 값이면 추가하지 않는다.

<details>
<summary>힌트 보기</summary>

재귀로 "이 자리에 넣고 바뀐 서브트리를 돌려준다" 패턴이에요.

```java
public void insert(int value) {
    root = insertNode(root, value);
}

private Node insertNode(Node node, int value) {
    if (node == null) return new Node(value);   // 빈 자리 → 새 노드
    if (value < node.value)      node.left  = insertNode(node.left, value);
    else if (value > node.value) node.right = insertNode(node.right, value);
    // 같은 값이면 무시(중복 안 넣음)
    return node;
}
```

</details>

#### 확인

여러 값을 삽입한 뒤 Step 3부터 Step 5까지의 순회 결과로 트리 구조를 확인한다.

### Step 3. 전위 순회 구현

#### 목표

루트, 왼쪽, 오른쪽 순서로 노드를 방문한다.

#### 구현 내용

1. 현재 노드가 `null`이면 재귀 호출을 종료한다.
2. 현재 노드의 값을 출력한다.
3. 왼쪽 서브트리를 순회한다.
4. 오른쪽 서브트리를 순회한다.

<details>
<summary>힌트 보기</summary>

```java
public void preOrder() {
    System.out.print("전위: ");
    preOrder(root);
    System.out.println();
}

private void preOrder(Node node) {
    if (node == null) return;
    System.out.print(node.value + " ");   // 1) 루트 먼저
    preOrder(node.left);                   // 2) 왼쪽
    preOrder(node.right);                  // 3) 오른쪽
}
```

</details>

#### 확인

예시 트리에서 다음 순서가 출력되는지 확인한다.


```java
    System.out.print("중위: ");

    System.out.println();

    if (node == null) return;
    inOrder(node.left);                   // 1) 왼쪽
    System.out.print(node.value + " ");   // 2) 루트 (가운데!)
    inOrder(node.right);                  // 3) 오른쪽
```

#### 구현 내용

1. 현재 노드가 `null`이면 재귀 호출을 종료한다.
2. 왼쪽 서브트리를 순회한다.
3. 오른쪽 서브트리를 순회한다.
4. 현재 노드의 값을 출력한다.

<details>
<summary>힌트 보기</summary>

```java
public void postOrder() {
    System.out.print("후위: ");
    postOrder(root);
    System.out.println();
}

private void postOrder(Node node) {
    if (node == null) return;
    postOrder(node.left);                 // 1) 왼쪽
    postOrder(node.right);                // 2) 오른쪽
    System.out.print(node.value + " ");   // 3) 루트 (마지막!)
}
```

세 순회를 나란히 보면, **`System.out.print` 줄이 맨 앞 / 가운데 / 맨 뒤로** 옮겨다닐 뿐이에요.

## 9. 선택 도전 과제

1. **레벨 순회**: `Queue`를 사용해 같은 깊이의 노드를 왼쪽부터 방문하는 BFS 구현
2. **트리 높이**: 가장 깊은 잎까지의 높이를 `1 + max(왼쪽 높이, 오른쪽 높이)` 방식으로 계산
3. **노드 개수**: 트리에 저장된 전체 노드 개수를 재귀로 계산
4. **잎 개수**: 왼쪽과 오른쪽 자식이 모두 없는 노드 개수를 계산
5. **값 탐색**: 특정 값이 트리에 존재하는지 확인하는 `search(int value)` 구현
6. **트리 구조 출력**: 트리를 옆으로 눕힌 형태로 출력해 노드 연결 관계 확인
7. **반복문 순회**: `Stack`을 사용해 재귀 없이 전위 또는 중위 순회 구현

# 숫자 업다운 게임 만들기 (Up & Down)

> 컴퓨터가 정한 숫자를 사용자가 맞히는 콘솔 게임을 구현한다. `Random`, `Scanner`, `if-else`, `while` 반복문을 활용해 자바 기본 문법을 연습한다.

---

## 1. 무엇을 만드나요?

컴퓨터가 1~100 중 하나의 숫자를 정하고, 사용자가 그 숫자를 맞히는 콘솔 게임을 구현한다.

사용자가 숫자를 입력하면 정답보다 큰지 작은지에 따라 `UP` 또는 `DOWN` 힌트를 출력한다.

정답을 맞힐 때까지 입력과 비교를 반복하고, 정답을 맞히면 몇 번 만에 맞혔는지 출력한다.

```text
숫자를 맞혀보세요! (1 ~ 100)
입력 > 50
UP! 더 큰 수입니다.
입력 > 75
DOWN! 더 작은 수입니다.
입력 > 63
DOWN! 더 작은 수입니다.
입력 > 58
정답입니다! 4번 만에 맞혔습니다.
```

## 2. 요구사항 정리 (기능 명세)

| 번호 | 기능     | 설명                                   |
| -- | ------ | ------------------------------------ |
| 1  | 정답 정하기 | 프로그램이 1~100 사이의 랜덤 숫자를 하나 정한다.       |
| 2  | 숫자 입력  | 사용자에게 숫자를 입력받는다.                     |
| 3  | 힌트 주기  | 입력값이 정답보다 작으면 `UP`, 크면 `DOWN`을 출력한다. |
| 4  | 반복     | 정답을 맞힐 때까지 입력과 힌트 출력을 반복한다.          |
| 5  | 시도 횟수  | 몇 번 만에 맞혔는지 세어서 출력한다.                |

---

## 3. 핵심 개념

### 1. 랜덤 숫자 만들기

`Random`을 사용해 1~100 사이의 정답을 만든다.

```java
Random rand = new Random();
int answer = rand.nextInt(100) + 1;
```

`nextInt(100)`은 0부터 99까지의 숫자를 반환한다.

따라서 1부터 100까지의 숫자를 만들기 위해 결과에 1을 더한다.

### 2. 비교해서 힌트 주기

입력값 `guess`와 정답 `answer`를 비교한다.

* `guess < answer`이면 정답이 더 크므로 `UP`을 출력한다.
* `guess > answer`이면 정답이 더 작으므로 `DOWN`을 출력한다.
* `guess == answer`이면 정답 메시지를 출력한다.

### 3. 맞힐 때까지 반복하기

정답을 맞히기 전까지 입력과 비교를 계속 반복한다.

정답을 맞히면 `break`를 사용해 반복문을 종료한다.

---

## 4. Step by Step

각 Step에는 목표, 할 일, 힌트, 확인 방법이 있다.

하나씩 실행해 보며 구현을 진행한다.

전체 코드는 `main` 메서드 하나에 작성해도 충분하다.

---

### Step 1. 정답 정하고 숫자 한 번 입력받기

**목표**: 컴퓨터가 랜덤 정답을 정하고, 사용자에게 숫자를 한 번 입력받는다.

**할 일**

1. `Random`으로 1~100 사이의 정답을 만든다.
2. `Scanner`로 숫자 하나를 입력받는다.
3. 테스트를 위해 정답을 잠시 출력한다.
4. 완성 후 테스트용 정답 출력은 삭제한다.

**힌트**

```java
import java.util.Random;
import java.util.Scanner;

Random rand = new Random();
int answer = rand.nextInt(100) + 1;

System.out.println("(테스트용 정답: " + answer + ")");

Scanner sc = new Scanner(System.in);

System.out.print("입력 > ");
int guess = sc.nextInt();
```

**확인**: 실행할 때마다 정답이 바뀌고, 입력한 숫자가 정상적으로 저장되면 성공이다.

---

### Step 2. 입력값과 정답 비교하기

**목표**: 입력한 숫자가 정답보다 큰지, 작은지, 같은지 판정한다.

**할 일**

* `if-else`문으로 `UP`, `DOWN`, 정답 세 경우를 나눈다.

**힌트**

```java
if (guess < answer) {
    System.out.println("UP! 더 큰 수입니다.");
} else if (guess > answer) {
    System.out.println("DOWN! 더 작은 수입니다.");
} else {
    System.out.println("정답입니다!");
}
```

**확인**: 정답보다 작은 값, 큰 값, 같은 값을 각각 입력했을 때 메시지가 올바르게 출력되면 성공이다.

---

### Step 3. 맞힐 때까지 반복하기

**목표**: 한 번만 비교하지 않고, 정답을 맞힐 때까지 계속 입력받는다.

**할 일**

1. 입력과 비교 코드를 `while (true)` 안으로 넣는다.
2. 정답을 맞히면 `break`로 반복을 종료한다.

**힌트**

```java
while (true) {
    System.out.print("입력 > ");
    int guess = sc.nextInt();

    if (guess == answer) {
        System.out.println("정답입니다!");
        break;
    } else if (guess < answer) {
        System.out.println("UP!");
    } else {
        System.out.println("DOWN!");
    }
}
```

**확인**: 정답을 맞힐 때까지 계속 입력을 받고, 맞히면 반복이 종료되면 성공이다.

---

### Step 4. 시도 횟수 세기

**목표**: 사용자가 몇 번 만에 정답을 맞혔는지 출력한다.

**할 일**

1. 반복문 밖에 `int count = 0;`을 선언한다.
2. 숫자를 입력받을 때마다 `count`를 1 증가시킨다.
3. 정답을 맞혔을 때 `count`를 함께 출력한다.

**힌트**

```java
int count = 0;

while (true) {
    int guess = sc.nextInt();
    count++;

    if (guess == answer) {
        System.out.println("정답입니다! " + count + "번 만에 맞혔습니다.");
        break;
    }

    // UP / DOWN 처리
}
```

**확인**: 정답을 맞힌 뒤 시도 횟수가 정확히 출력되면 성공이다.

---

### Step 5. 마무리 다듬기

**목표**: 사용자가 게임을 편하게 실행할 수 있도록 예외 상황을 보완한다.

**점검 항목**

* [ ] 시작할 때 입력 범위인 1~100을 안내하는지 확인한다.
* [ ] 테스트용 정답 출력을 삭제했는지 확인한다.
* [ ] 1~100 밖의 숫자를 입력했을 때 안내 메시지가 출력되는지 확인한다.
* [ ] 숫자가 아닌 값을 입력해도 프로그램이 종료되지 않도록 처리했는지 확인한다.

**힌트**

```java
if (guess < 1 || guess > 100) {
    System.out.println("1~100 사이로 입력해 주세요.");
    continue;
}
```

범위를 벗어난 입력은 무효 처리하고 다시 입력받는다.

여기까지 통과하면 업다운 게임이 완성된다.

## 5. 최종 완성 체크리스트

## 6. 선택 도전 과제

1. **다시 하기**: 정답을 맞힌 뒤 한 판 더 할지 입력받아 반복
2. **기회 제한**: 정해진 횟수 안에 맞히지 못하면 게임 오버 처리
3. **난이도 선택**: 시작 시 쉬움, 보통, 어려움 중 하나를 선택해 숫자 범위 변경
4. **최고 기록**: 가장 적은 시도 횟수를 저장해서 출력
5. **역할 바꾸기**: 사용자가 정답을 정하고 컴퓨터가 맞히도록 구현

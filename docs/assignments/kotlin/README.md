# Kotlin 과제 정리

Kotlin 기본 문법, 함수, 제어문, 배열, 객체지향, 추상 클래스, 인터페이스, 위임을 실습한 과제 모음이다.

각 과제는 문서와 실제 Kotlin 구현 코드를 함께 확인할 수 있도록 정리한다.

| --- | ------------------------------------------ | ------------------------------------------------------------------ |
| 자판기 | [vending-machine.md](./vending-machine.md) | Kotlin 기본 문법과 제어문, 함수를 활용해 돈 투입, 음료 구매, 잔액 처리, 종료 기능을 구현한 자판기 프로그램 |

## 객체지향 · 추상 클래스 · 인터페이스

| 과제      | 문서                                               | 설명                                                                |

## 학습 흐름

1. Kotlin 기본 문법과 제어문, 함수를 활용해 콘솔 프로그램의 전체 실행 흐름을 구성한다.
2. 2차원 배열을 활용해 여러 데이터를 저장하고 조회, 수정, 삭제하는 데이터 관리 흐름을 구현한다.
3. 추상 클래스와 다형성으로 회원 구조를 객체지향적으로 분리하고, 인터페이스와 위임을 활용해 저장소 규약과 구현을 분리하는 확장 구조를 구현한다.

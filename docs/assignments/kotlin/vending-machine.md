# 자판기 만들기 - Kotlin 기본 문법

변수, 함수, 조건문, 반복문을 이용해 동작하는 자판기를 구현한다.

클래스와 객체는 사용하지 않으며, 하나의 파일 안에 여러 함수를 정의하고 `main`에서 각 함수를 조합하는 것을 목표로 한다.

---

## 1. 구현 기능

돈을 넣고 번호로 음료를 선택하면 해당 음료가 출력되고 금액이 차감된다. 프로그램을 종료하면 남은 금액을 잔돈으로 반환한다.

```text
============== 자판기 ==============
[1]콜라 : 500, [2]사이다 : 500, [3]환타 : 300, [4]물 : 200, [5]돈 넣기, [6]종료
현재 금액 : 0
====================================
원하는 메뉴를 선택하시오.
5
돈을 넣으시오.
1000
============== 자판기 ==============
[1]콜라 : 500, [2]사이다 : 500, [3]환타 : 300, [4]물 : 200, [5]돈 넣기, [6]종료
현재 금액 : 1000
====================================
원하는 메뉴를 선택하시오.
1
콜라가 나왔습니다.
...
원하는 메뉴를 선택하시오.
6

잔돈 500원이 반환되었습니다.
```

---

## 2. 학습 목표

| 개념             | 활용                                                              |
| -------------- | --------------------------------------------------------------- |
| `val` / `var`  | 변경되지 않는 값과 변경되는 값을 구분한다. (`choice`는 `val`, `totalMoney`는 `var`) |
| `const val`    | 음료 가격과 같이 변경되지 않는 값을 상수로 선언한다.                                  |
| 함수 (`fun`)     | 메뉴 출력, 입력, 계산 기능을 각각 함수로 분리한다.                                  |
| 매개변수와 반환값      | `calcMoney(totalMoney, price)`와 같이 함수 간에 값을 전달한다.               |
| 문자열 템플릿 (`$`)  | `"현재 금액 : $totalMoney"`와 같이 변수 값을 문자열에 포함한다.                    |
| `when`         | 메뉴 번호에 따라 실행할 기능을 분기한다.                                         |
| `if ~ else`    | 현재 금액이 음료 가격보다 부족한지 확인한다.                                       |
| `while (true)` | 메뉴 선택 과정을 반복한다.                                                 |
| `return`       | 반복과 프로그램 실행을 종료한다.                                              |
| `readln()`     | 사용자 입력을 받는다.                                                    |

## 3. 핵심 개념

### 3.1 기능을 함수로 분리하기

`main` 하나에 모든 로직을 작성하지 않고 기능별로 함수를 분리한다.

| 함수                             | 역할                         |
| ------------------------------ | -------------------------- |
| `printMenu(totalMoney)`        | 메뉴와 현재 금액을 출력한다.           |
| `getChoice()`                  | 메뉴 번호를 입력받아 반환한다.          |
| `getMoney()`                   | 넣을 금액을 입력받아 반환한다.          |
| `calcMoney(totalMoney, price)` | 음료 가격을 차감한 결과를 반환한다.       |
| `calcMoneyException()`         | 잔돈 부족 메시지를 출력한다.           |
| `main()`                       | 각 함수를 호출해 전체 자판기 흐름을 제어한다. |

값을 출력하기만 하는 함수는 별도의 반환값이 없으며 반환 자료형 `Unit`을 생략할 수 있다.

값을 반환하는 함수는 반환 자료형을 명시한다.

### 3.2 반복과 분기

자판기는 다음 흐름을 반복한다.

```text
메뉴 출력 → 입력 → 처리 → 메뉴 출력
```

이를 `while (true)`와 `when`을 이용해 구현한다.

```kotlin
while (true) {
    printMenu(totalMoney)
    val choice = getChoice()

    when (choice) {
        ...
    }
}
```

`while (true)`는 별도의 종료 조건이 없는 무한 반복이므로 `return`을 이용해 프로그램을 종료하는 분기가 필요하다.

### 3.3 사용자 입력

`readln()`은 사용자가 입력한 한 줄을 `String`으로 반환한다.

```kotlin
val line = readln()
val number = line.toInt()
```

두 문장은 다음과 같이 작성할 수 있다.

```kotlin
val number = readln().toInt()
```

Java의 `Scanner`와 `nextInt()`를 이용한 입력과 유사한 역할을 한다.

## 5. Step by Step

각 Step에서는 목표, 구현 내용, 힌트, 확인 방법을 기준으로 순차적으로 기능을 구현한다.

---

### Step 1. 상수 선언과 메뉴 출력

**목표**

음료 가격을 상수로 선언하고 메뉴를 출력하는 함수를 구현한다.

**구현 내용**

1. 파일 최상위에 `const val`을 이용해 `COKE`, `CIDER`, `FANTA`, `WATER`를 선언한다.
2. `printMenu(totalMoney: Int)` 함수를 작성한다.
3. 현재 금액은 문자열 템플릿을 이용해 출력한다.

**힌트**

```kotlin
const val COKE = 500
const val CIDER = 500
const val FANTA = 300
const val WATER = 200

fun printMenu(totalMoney: Int) {
    println("============== 자판기 ==============")
    println("[1]콜라 : 500, [2]사이다 : 500, [3]환타 : 300, [4]물 : 200, [5]돈 넣기, [6]종료")
    println("현재 금액 : $totalMoney")
    println("====================================")
}
```

`const val`은 변경할 수 없는 상수를 선언할 때 사용한다. 음료 가격처럼 프로그램 실행 중 변경되지 않는 값에 사용할 수 있다.

`printMenu()`는 반환값이 없으므로 반환 자료형 `Unit`을 생략한다.

**확인**

`main`에서 `printMenu(0)`을 호출했을 때 메뉴가 정상적으로 출력되는지 확인한다.

---

### Step 2. 입력 함수 작성

**목표**

메뉴 번호와 넣을 금액을 각각 입력받는 함수를 구현한다.

**구현 내용**

1. `getChoice(): Int`는 메뉴 번호를 입력받아 `Int`로 반환한다.
2. `getMoney(): Int`는 넣을 금액을 입력받아 `Int`로 반환한다.

**힌트**

```kotlin
fun getChoice(): Int {
    println("원하는 메뉴를 선택하시오.")

    return readln().toInt()
}
```

값을 반환하는 함수이므로 반환 자료형 `Int`를 명시한다.

`getMoney()`도 같은 구조로 작성하고 출력 안내 문구만 변경한다.

**확인**

```kotlin
println(getChoice())
```

를 실행했을 때 입력한 숫자가 정상적으로 출력되는지 확인한다.

---

### Step 3. 금액 계산 함수

**목표**

음료 가격을 차감한 결과를 반환하는 함수와 잔돈 부족 메시지를 출력하는 함수를 구현한다.

**구현 내용**

1. `calcMoney(totalMoney: Int, price: Int): Int`는 현재 금액에서 음료 가격을 차감한 값을 반환한다.
2. `calcMoneyException()`은 `"잔돈이 부족합니다."`를 출력한다.

**힌트**

```kotlin
fun calcMoney(totalMoney: Int, price: Int): Int {
    return totalMoney - price
}
```

`calcMoney()`는 금액 계산만 담당한다.

현재 금액이 300이고 음료 가격이 500이면 다음과 같은 결과가 반환된다.

```text
-200
```

음수 여부를 이용해 구매 가능 여부를 판단할 수 있다.

함수 본문이 한 줄인 경우 다음과 같이 표현식 함수로 작성할 수도 있다.

```kotlin
fun calcMoney(totalMoney: Int, price: Int): Int = totalMoney - price
```

**확인**

```kotlin
println(calcMoney(300, 500))
```

을 실행했을 때 `-200`이 출력되는지 확인한다.

---

### Step 4. 메뉴 반복 구현

**목표**

메뉴가 반복해서 출력되도록 `main`의 기본 구조를 작성한다.

**구현 내용**

1. `main` 안에 현재 금액을 저장할 변수를 선언한다.
2. 값이 계속 변경되므로 `var`를 사용한다.
3. `while (true)` 안에서 `printMenu()`와 `getChoice()`를 호출한다.
4. 입력한 메뉴 번호를 임시로 출력해 반복 동작을 확인한다.

**힌트**

```kotlin
fun main() {
    var totalMoney = 0

    while (true) {
        printMenu(totalMoney)
        val choice = getChoice()

        println("입력한 번호: $choice")
    }
}
```

`totalMoney`는 프로그램 실행 중 계속 변경되므로 `var`로 선언한다.

`choice`는 한 번의 반복 과정에서 변경하지 않으므로 `val`로 선언한다.

현재 단계에서는 종료 로직이 없으므로 무한 반복된다. 실행 중에는 `Ctrl + C`로 종료할 수 있으며 다음 단계에서 종료 기능을 추가한다.

**확인**

번호를 입력할 때마다 메뉴가 다시 출력되는지 확인한다.

---

### Step 5. `when`을 이용한 음료 구매

**목표**

1~4번 메뉴를 선택했을 때 음료를 출력하고 현재 금액에서 음료 가격을 차감한다.

**구현 내용**

1. `when (choice)`를 이용해 메뉴별 로직을 분기한다.
2. 각 분기에서 `calcMoney()`를 이용해 차감 결과를 계산한다.
3. `if`를 이용해 계산 결과가 음수인지 확인한다.

   * 음수인 경우 `calcMoneyException()`을 호출한다.
   * 음수가 아닌 경우 `totalMoney`를 계산 결과로 변경하고 음료 출력 메시지를 표시한다.

**힌트**

```kotlin
var result = -1

when (choice) {
    1 -> {
        result = calcMoney(totalMoney, COKE)

        if (result < 0) {
            calcMoneyException()
        } else {
            totalMoney = result
            println("콜라가 나왔습니다.")
        }
    }

    2 -> {
        // 사이다도 같은 방식으로 처리한다.
    }

    // 3번 환타, 4번 물도 같은 방식으로 처리한다.
}
```

`totalMoney = result`는 현재 금액이 부족하지 않은 경우에만 실행해야 한다.

계산 결과를 먼저 `totalMoney`에 대입하면 구매할 수 없는 경우에도 현재 금액이 음수가 될 수 있다.

Kotlin의 `when`은 Java의 `switch`와 달리 각 분기마다 `break`를 작성하지 않는다.

한 분기에서 여러 문장을 실행하는 경우 중괄호 `{ }`로 묶는다.

**확인**

현재 금액이 `0`인 상태에서 1번을 선택했을 때 `"잔돈이 부족합니다."`가 출력되는지 확인한다.

---

### Step 6. 돈 넣기, 종료, 잘못된 입력 처리

**목표**

5번 돈 넣기, 6번 종료, 그 외 잘못된 메뉴 입력을 처리한다.

**구현 내용**

1. `5 ->`에서는 `getMoney()`로 입력받은 금액을 `totalMoney`에 더한다.
2. `6 ->`에서는 남은 금액을 출력하고 `return`으로 프로그램을 종료한다.
3. `else ->`에서는 잘못된 입력 메시지를 출력한다.

**힌트**

```kotlin
5 -> totalMoney += getMoney()

6 -> {
    println("\n잔돈 ${totalMoney}원이 반환되었습니다.")
    return
}

else -> println("잘 못 입력하셨습니다. 다시 입력해주세요.")
```

실행할 코드가 한 줄인 경우 중괄호 없이 `->` 뒤에 바로 작성할 수 있다.

`\n`은 줄바꿈을 의미한다.

`${totalMoney}원`과 같이 변수명 바로 뒤에 문자열이 이어지는 경우 중괄호를 사용해 변수 범위를 구분한다.

`return`은 `main` 함수의 실행을 종료하며, 이에 따라 `while (true)` 반복도 함께 종료된다.

**확인**

돈 넣기, 음료 구매, 프로그램 종료 과정이 모두 정상적으로 동작하는지 확인한다.

## 8. 선택 도전 과제

### 8.1 숫자가 아닌 입력 처리

현재 구현에서는 `abc`와 같은 값을 입력하면 숫자로 변환하는 과정에서 예외가 발생한다.

`toIntOrNull()`과 엘비스 연산자(`?:`)를 이용해 숫자가 아닌 입력은 `-1`로 처리한다.

```kotlin
return readln().toIntOrNull() ?: -1
```

### 8.2 중복 코드 줄이기

1~4번 메뉴의 구매 로직은 음료 이름과 가격만 다르고 대부분 동일하다.

다음과 같은 함수를 이용해 공통 구매 로직으로 분리할 수 있다.

```kotlin
buy(totalMoney: Int, price: Int, name: String): Int
```

이를 적용하면 `when`의 각 분기를 다음과 같이 단순화할 수 있다.

```kotlin
1 -> totalMoney = buy(totalMoney, COKE, "콜라")
```

### 8.3 판매 기록

판매한 음료 개수를 저장하고 프로그램 종료 시 총 판매 개수와 매출을 출력한다.

### 8.4 재고 관리

음료별 남은 수량을 `var`로 관리하고 재고가 `0`인 경우 `"품절입니다."`를 출력한다.

### 8.5 금액 단위 검사

100원 단위가 아닌 금액이 입력되면 금액을 받지 않도록 처리한다.

예를 들어 `350`원이 입력된 경우 다음과 같은 메시지를 출력한다.

```text
100원 단위로 넣어 주세요.
```

`%` 연산자를 이용해 입력 금액이 100원 단위인지 확인한다.

### 8.6 거스름돈 내역

프로그램 종료 시 잔돈을 500원과 100원 단위로 나누어 반환 개수를 계산한다.

`/`와 `%` 연산자를 이용한다.

## 9. 정리

변수와 상수, 함수의 매개변수와 반환값, 조건문, 반복문, 사용자 입력을 조합해 자판기의 전체 실행 흐름을 구현한다.

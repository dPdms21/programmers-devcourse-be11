완전범죄 — 2차원 DP 단계별 시각화

예제: info = [[1,2], [2,3], [2,1]], n = 4, m = 4

info
[[1,2], [2,3], [2,1]]
A 조건
A < 4
B 조건
B < 4
현재 단계

1. 현재 가능한 DP 상태

dp[a][b] == true는 A 흔적이 a, B 흔적이 b인 상태가 가능하다는 뜻이다.

2. 이번 물건 처리

3. 처리 전 / 처리 후 상태

처리 전 dp
처리 후 next → dp

4. 코드와 연결

class Solution {
    public int solution(int[][] info, int n, int m) {
        boolean[][] dp = new boolean[n][m];
        dp[0][0] = true;

        for (int[] item : info) {
            int aTrace = item[0];
            int bTrace = item[1];

            boolean[][] next = new boolean[n][m];

            for (int a = 0; a < n; a++) {
                for (int b = 0; b < m; b++) {
                    if (!dp[a][b]) continue;

                    if (a + aTrace < n) {
                        next[a + aTrace][b] = true;
                    }

                    if (b + bTrace < m) {
                        next[a][b + bTrace] = true;
                    }
                }
            }

            dp = next;
        }

        for (int a = 0; a < n; a++) {
            for (int b = 0; b < m; b++) {
                if (dp[a][b]) return a;
            }
        }

        return -1;
    }
}

5. 변수 의미

변수의미
info각 물건의 [A 흔적, B 흔적]
nA가 잡히는 기준값
mB가 잡히는 기준값
a현재까지 누적된 A 흔적
b현재까지 누적된 B 흔적
aTrace현재 물건을 A가 훔쳤을 때 추가 흔적
bTrace현재 물건을 B가 훔쳤을 때 추가 흔적
dp[a][b]A=a, B=b 상태가 가능한지 여부
next현재 물건까지 처리한 다음 상태
